# Abartılı Boş Selam Makinesi

## Bu Repo Ne Yapar?

Hiçbir şey. Ama çok abartılı bir şekilde hiçbir şey yapar.

Bu Python scripti, size rastgele, aşırı ciddiyetle abartılmış Türkçe selamlar üretir. Gerçekten çalışır. Gerçekten işe yaramaz. Ama o kadar abartılı ki, neredeyse bir anlamı varmış gibi hissedersiniz.

### Nasıl Çalışır?

1. Scripti çalıştırırsınız.
2. Size "Merhaba" demek yerine, "Ey şanlı kullanıcı, bu selamın arkasında evrenin tüm gücü ve biraz da kahve var!" tarzında şeyler basar.
3. Hepsi bu. Hayatınız değişmez.

### Kurulum

```bash
python selam_makinesi.py
```

Başka bir şey yapmanıza gerek yok. Bu kadar basit. Bu kadar absürt.
